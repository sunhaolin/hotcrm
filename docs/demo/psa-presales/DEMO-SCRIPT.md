## 0. 演示准备

- **重置并启动**：`git checkout demo/psa-presales && pnpm install && pnpm demo:reset && pnpm dev`（端口 4001；首启回放 40 条中文种子，等日志安静约 20–30 秒）。
- **演示人员**：`node scripts/demo-psa-staff.mjs` — 创建 6 名中文同事（张伟 客户经理 / 李娜 解决方案经理·资源报价 / 王强 交付经理·项目经理 / 赵敏 项目总监 / 刘洋 QA / 陈晨 分包 TS），并填入铁三角、项目角色、工时填报人。
- **登录与语言**：浏览器打开 `http://localhost:4001/_console/login`，登录 admin@objectos.ai / admin123；浏览器语言设为简体中文，主页「我的应用」点 HotCRM。
- **排练后复位**：审批状态字段只读，排练时发起过的审批不能手工改回草稿：演示前重新 `pnpm demo:reset && pnpm dev`，再跑一次人员脚本，七条现场记录即回到草稿。
- **自检 2 分钟**：交付项目列表：DLV-0002 预算消耗 132、DLV-0001 约 53；项目成本仪表板四块磁贴有数；待我审批为空；三条"现场提交"的记录处于草稿：客户「东方联合银行」、线索「张建国」、商机「东方联合银行信贷风控平台」（立项状态 未立项）。
- **不要点的地方**：设置 → 系统设置里的元数据校验 / 文档一致性守卫（本分支刻意不过 `pnpm verify`）；语言不要切到西班牙语 / 日语（新对象只做了中文和英文）。
