> 分支 `demo/psa-presales`，对应总纲 [#2](https://github.com/sunhaolin/hotcrm/issues/2)。
> 第四轮起这条分支按 CI 门槛整理（种子并入默认组合、四语言包、文档、结构性测试），以 PR 合并到 `main`；演示本身用 `zh-demo` 组合启动（见下）。
> **逐步骤的演示脚本（每一步对应需求表的哪一行、配截图）见 [`DEMO-SCRIPT.md`](./DEMO-SCRIPT.md)**；本手册只管启动、自检、口径和禁区。
> 截图均在本目录，按需求表步骤序号命名：`S{步骤}-{画面}.png`。

## 0. 启动与登录

```bash
git checkout demo/psa-presales
pnpm install
pnpm demo:reset:zh                # 清空 .objectstack/data，按 zh-demo 组合重建（只打包中文种子）
pnpm dev:zh                       # 端口 4001；首次启动回放约 240 条中文种子，等日志安静约 30–40 秒
node scripts/demo-psa-staff.mjs   # 另开终端：创建 6 名中文同事并填入负责人、铁三角、项目角色、填报人 / 出差人 / 申请人 / 经办人
```

- 两条 `:zh` 脚本只是在 `HOTCRM_COMPOSITION=zh-demo` 下跑 `pnpm demo:reset` / `pnpm dev`。**不要**用裸的 `pnpm dev` 演示：默认组合把标准英文演示数据（Acme Corporation 那一套）和中文数据一起回放，客户列表里会混进英文客户。构建和启动都要带这个变量——种子在 `pnpm build` 时打进 `dist/objectstack.json`，dev server 改代码后的自动重建也读它。

- 若启动时刷屏 `NODE_MODULE_VERSION … requires …`：`pnpm rebuild better-sqlite3` 后重启（AGENTS.md 已知坑）。
- 浏览器打开 <http://localhost:4001/_console/login>，登录 **admin@objectos.ai / admin123**（仅开发环境的种子管理员）。
- 控制台跟随浏览器语言；把浏览器语言设为 **简体中文**，界面即为中文（`S00-进入应用.png`）。
- **服务端语言单独设置**：记录"动态"里的句子（如「创建了 线索 "孙浩"」）是在写入时按租户默认语言生成的，与浏览器语言无关。演示前在 **设置 → 本地化 → 默认语言** 选 **简体中文**，或直接用 `OS_LOCALIZATION_LOCALE=zh-CN pnpm dev` 启动。设置之前已写入的动态、通知仍是英文，不会回溯。
- 主页"我的应用"点 **HotCRM** 进入应用；左侧导航里有 **销售** 组和新的 **项目管理** 组。
- **数据全部为中文**：`zh-demo` 组合只回放中文种子，标准英文演示数据不打包。数据是一家软件公司（华软股份）一年的业务面：14 家客户、14 条线索、13 个商机（5 赢 1 丢）、6 份合同、8 个售前项目、7 个交付项目及其成本计划、工时、出差、请假、开票、收款、采购与订单，5 个产品、2 份报价；40 步脚本走的仍是华信 / 北辰 / 东方联合银行 / 中招国际那条主线；页面文案、字段分组、仪表板、审批流名称也都是中文。演示人员（张伟 / 李娜 / 王强 / 赵敏 / 刘洋 / 陈晨）由上面的脚本创建，口令 `Demo12345!`，只在开发环境有效。
- 每次改 `src/` 都会让 dev server 重启并**重放种子**：种子里的状态会盖回去（现场提交的记录回到草稿），审批请求不会重放。演示前不要再动代码。
- **审批状态是只读字段**（表单改不了、API 也写不进）——排练时点过「发起审批」的记录不能手工改回草稿。演示前重新 `pnpm demo:reset:zh && pnpm dev:zh` 并再跑一次人员脚本，七条现场记录（客户东方联合银行、线索张建国、商机东方联合银行信贷风控平台、工时表 TS-0007、预算调整 BA-0001、出差「华信投标答疑现场支持」、请假 LV-0002，另有售前项目「江南医药 GMP」）即回到草稿。

## 3. 不要点的地方

- **设置 / 系统设置** 里的元数据校验之类的守卫可以点，但没必要——它们展示的是平台自检，不是客户的业务。
- 语言不要切到 **西班牙语 / 日语**——四种语言包都齐了，但日语、西语的新对象译文是机器初译，没有人工校对。
- 审批中心里**不必点开请求详情面板**：面板里的字段名是平台面板直出的英文原名（Amount / Stage …）；勾选行 → 通过即可。
- 已成交的商机（北辰 MES 二期）只允许改描述 / 下一步——这是标准产品对已关闭商机的保护，不要在它上面演示改铁三角。
