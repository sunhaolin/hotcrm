# 演示手册 — 项目型销售 + 项管平台（demo/psa-presales）

> 分支 `demo/psa-presales`，对应总纲 [#2](https://github.com/sunhaolin/hotcrm/issues/2)。
> 这是一次性演示分支：只保证 `pnpm validate && pnpm build` 为绿，**永不合并**；若立项做行业模板，这里的对象迁移到独立包。
> **逐步骤的演示脚本（每一步对应需求表的哪一行、配截图）见 [`DEMO-SCRIPT.md`](./DEMO-SCRIPT.md)**；本手册只管启动、自检、口径和禁区。
> 截图均在本目录，按需求表步骤序号命名：`S{步骤}-{画面}.png`。

## 0. 启动与登录

```bash
git checkout demo/psa-presales
pnpm install
pnpm demo:reset                   # 清空 .objectstack/data 并重建
pnpm dev                          # 端口 4001；首次启动回放 40 条中文种子，等日志安静约 20–30 秒
node scripts/demo-psa-staff.mjs   # 另开终端：创建 6 名中文同事并填入铁三角 / 项目角色 / 工时填报人
```

- 若启动时刷屏 `NODE_MODULE_VERSION … requires …`：`pnpm rebuild better-sqlite3` 后重启（AGENTS.md 已知坑）。
- 浏览器打开 <http://localhost:4001/_console/login>，登录 **admin@objectos.ai / admin123**（仅开发环境的种子管理员）。
- 控制台跟随浏览器语言；把浏览器语言设为 **简体中文**，界面即为中文（`S00-进入应用.png`）。
- **服务端语言单独设置**：记录"动态"里的句子（如「创建了 线索 "孙浩"」）是在写入时按租户默认语言生成的，与浏览器语言无关。演示前在 **设置 → 本地化 → 默认语言** 选 **简体中文**，或直接用 `OS_LOCALIZATION_LOCALE=zh-CN pnpm dev` 启动。设置之前已写入的动态、通知仍是英文，不会回溯。
- 主页"我的应用"点 **HotCRM** 进入应用；左侧导航里有 **销售** 组和新的 **项目管理** 组。
- **数据全部为中文**：这条分支只回放中文种子（华信科技、北辰智能制造、东方联合银行、中招国际），标准英文演示数据已排除；页面文案、字段分组、仪表板、审批流名称也都是中文。演示人员（张伟 / 李娜 / 王强 / 赵敏 / 刘洋 / 陈晨）由上面的脚本创建，口令 `Demo12345!`，只在开发环境有效。
- 每次改 `src/` 都会让 dev server 重启并**重放种子**：种子里的状态会盖回去（三条"现场提交"的记录回到草稿），审批请求不会重放。演示前不要再动代码。

## 3. 不要点的地方

- **设置 / 系统设置** 里的元数据校验、文档一致性之类的守卫——这条分支刻意没过 `pnpm verify`（文档覆盖、四语言、token 天花板），那里会红。
- 语言不要切到 **西班牙语 / 日语**——新对象只做了中文和英文，其余会回退到英文键名。
- 审批中心里**不必点开请求详情面板**：面板里的字段名是平台面板直出的英文原名（Amount / Stage …）；勾选行 → 通过即可。
- 已成交的商机（北辰 MES 二期）只允许改描述 / 下一步——这是标准产品对已关闭商机的保护，不要在它上面演示改铁三角。
