# 專案財務

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

四種記錄承載一個交付專案的錢：它向客戶**開的票**、**收到的款**、向分包商和供應商**採購的東西**，以及履行合約的**訂單**。每一種都是交付專案的子記錄——從專案記錄頁或 **Project Finance** 群組下各自的側邊欄項目新建——每一種都彙總到專案上，所以[交付專案](/zh-Hant/docs/projects/delivery-projects)和[專案財務儀表板](/zh-Hant/docs/analytics/dashboards)永遠一致。

## 開票

**開票**（`crm_invoice`）記錄一張對著專案銷售合約開出的發票：發票號、類型（*增值稅專票、增值稅普票、電子發票*）、金額、開票日期、狀態、開給哪個客戶和哪份合約，以及經辦人。

| 狀態 | 含義 |
| --- | --- |
| **草稿** | 已準備，尚未開出 |
| **已開票** | 已開給客戶 |
| **已寄送** | 已寄出，等待付款 |
| **已付款** | 已全額收款 |
| **作廢** | 已取消——**不計入**專案的已開票 |

發票上的**已收金額**是記到它上面的收款的彙總，**未收金額**是差額；都不用手填。

## 收款

**收款**（`crm_collection`）是收到的錢：金額、日期、方式（*銀行轉帳、支票、銀行匯票、其他*）、銀行流水號、它核銷的發票，以及所屬專案和客戶。對著發票登記收款，會同時改變那張發票的已收與未收金額、專案的已收款與應收餘額。

## 採購合約

**採購合約**（`crm_purchase_contract`）是專案採購進來的東西：類型（*分包、軟體、硬體、其他*）、供應商、金額、日期、狀態（*草稿 / 生效 / 已完成 / 已終止*）、已付與未付金額。*已終止*的合約**不計入**專案的採購合約合計。

## 銷售訂單

**銷售訂單**（`crm_sales_order`）是在專案合約下下達的訂單：訂單號、金額、下單日期、狀態（*待處理 / 進行中 / 已交付 / 已驗收*）、客戶和合約。訂單彙總進專案的銷售訂單合計。

## 系統自動做的事

- **每個合計都是彙總**——已開票（不計作廢）、已收款、應收餘額、採購合約合計（不計已終止）和銷售訂單合計都在交付專案上，子記錄每次儲存都重算。
- **這裡沒有審批**——財務記錄不帶審批流程；管控靠上面的狀態和專案自身的共用。

## 共用

四種記錄都在交付專案下*由父層控制*：看得到專案的人看得到它的開票、收款、採購合約和銷售訂單，別人看不到。它們為了方便也帶一個客戶欄位，但可見性從不跟隨客戶——透過區域規則共用給代表的客戶，代表只在能看到背後交付專案的情況下才看到該客戶的發票。

## 給財務的提示

- ✅ **開錯的發票作廢，不要刪除**——作廢保留了稽核軌跡，也會自己從合計裡掉出去。
- ✅ **收款對著發票登記，而不只是對著專案**，發票上的未收金額才誠實。
- ✅ **黃了的採購合約置為已終止，而不是刪除**，理由相同。
