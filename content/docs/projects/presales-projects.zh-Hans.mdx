# 售前项目

**售前项目**（`crm_presales_project`）就是投标：从商机立项到合同签署之间，销售与方案团队做的那段工作。它挂在商机和客户下，承载 **Bizcase**——成本估算与报价——是高管在开交付项目之前要审批的东西。

## 售前项目记录存什么

| 分组 | 内容 |
| --- | --- |
| **项目信息** | 名称、别名、商机、客户、项目类型、业务类别、计划日期、描述 |
| **项目角色** | 客户经理、项目经理、项目总监、项目 QA、资源报价负责人——五个人员字段，记录里写明投标的每一部分归谁 |
| **成本估算与报价** | 人工成本、第三方服务成本、采购成本、项目费用、总成本、报价金额、毛利率、售前工时、售前人工实际 |
| **信息安全** | 安全等级与备注——投标出门之前必须声明的分类 |
| **审批** | 审批状态*（只读）*、审批日期 |

**总成本**是四项成本之和，**毛利率**由它和报价金额算出。两者都不用手填。

**售前工时**与**售前人工实际**是汇总：记到这个售前项目上、且*已审批*的[工时表](/zh-Hans/docs/projects/timesheets-and-leave)的工时和成本。草稿或被驳回的工时表一分不算，所以记录上的数就是财务认可的数。

## 审批

投标由**售前立项审批**流程审批。点记录页顶部的**发起审批**——*审批状态*字段本身在表单和 API 上都是只读的，没有别的办法改它。提交后记录锁定；审批发给高管；结论出来后回写状态与审批日期，并通知负责人。被驳回的投标可以改完再提。

只有**已通过**的售前项目才会往交付项目里带东西——见[交付项目](/zh-Hans/docs/projects/delivery-projects)里的*系统自动做的事*。

## 共享

售前项目是**私有**的，没有共享规则放开它：负责人看自己的，销售经理和系统管理员看全部。通过区域规则共享给销售代表的客户，并不会把该客户的售前项目一并带来——这种客户上的*售前项目*相关列表，代表只看到自己的那些。

## 提示

- ✅ **四项成本都估，哪怕某一项是零。** 交付项目会把它们作为四条成本计划行带入，空着的一行就是没人做预算的一行。
- ✅ **售前工时记到售前项目上，不要记到商机上。** 只有记在项目上的工时表才会汇总进售前人工实际。
- ✅ **把 Bizcase 文档作为附件传上去。** 售前项目已启用附件。
