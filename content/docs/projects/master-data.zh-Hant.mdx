# 主資料

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

兩張小表撐著本模組的其它一切。**費率卡**（`crm_rate_card`）說明某個職級一小時值多少錢；**簽約主體**（`crm_legal_entity`）是我方公司裡簽合約的那個法人。兩者都在 **Master Data** 導覽群組下，該群組在應用載入時是摺疊的。

## 費率卡

| 欄位 | 含義 |
| --- | --- |
| 名稱、職級代碼 | 職級——*高級工程師*、*架構師*、*專案經理*…… |
| 小時費率、日費率 | 該職級的成本；小時費率是工時表和人工計畫行複製的那個數 |
| 生效日期、失效日期、啟用 | 卡的有效期；選啟用中的卡 |
| 備註 | 費率的前提假設 |

用在哪裡：

- **工時表**選了職級，`timesheet_rate_fill` 把小時費率複製到表上——見[工時與請假](/zh-Hant/docs/projects/timesheets-and-leave)；
- **人工成本計畫行**選了職級，`cost_plan_line_fill` 把小時費率複製為單價——見[交付專案](/zh-Hant/docs/projects/delivery-projects)。

兩者都是儲存時的複製。改費率卡不會給任何已儲存的東西重新定價：已審批的工時表保留審批時的費率，這正是財務要的行為。

## 簽約主體

| 欄位 | 含義 |
| --- | --- |
| 名稱、簡稱、統一社會信用代碼、法定代表人、地址 | 法人本身 |
| 開戶行、銀行帳號 | 客戶往哪裡付款 |
| 啟用、備註 | 是否還能被選 |

**商機**在*簽約主體*分組裡指定它的簽約主體（見[商機](/zh-Hant/docs/sales/opportunities)），所以合約還沒出現之前，投標就已經寫明由哪家公司簽約。

## 共用

兩張表都是**公開讀寫**：所有人都能讀，對該物件有編輯權的所有人都能改，沒有歸屬擋在中間。主資料就是這樣——一份共用的清單——這也是它們不帶按負責人篩的檢視的原因。實務中費率卡由 PMO 維護，簽約主體由財務維護；若貴司想收窄，管理員把 OWD 降為*公開唯讀*，只給一種權限設定檔編輯權即可。見[共用與安全](/zh-Hant/docs/administration/sharing-and-security)。

## 給管理員的提示

- ✅ **要停用一張費率卡，清掉*啟用*並填上*失效日期***，而不是改它的費率——新的職級費率就是一張新卡，一小時曾經值多少錢的歷史才讀得回來。
- ✅ **一個法人註冊一條主體**；統一社會信用代碼是自然鍵。
