# 项目财务

四种记录承载一个交付项目的钱：它向客户**开的票**、**收到的款**、向分包商和供应商**采购的东西**，以及履行合同的**订单**。每一种都是交付项目的子记录——从项目记录页或 **Project Finance** 分组下各自的侧边栏条目新建——每一种都汇总到项目上，所以[交付项目](/zh-Hans/docs/projects/delivery-projects)和[项目财务仪表板](/zh-Hans/docs/analytics/dashboards)永远一致。

## 开票

**开票**（`crm_invoice`）记录一张对着项目销售合同开出的发票：发票号、类型（*增值税专票、增值税普票、电子发票*）、金额、开票日期、状态、开给哪个客户和哪份合同，以及经办人。

| 状态 | 含义 |
| --- | --- |
| **草稿** | 已准备，尚未开出 |
| **已开票** | 已开给客户 |
| **已寄送** | 已寄出，等待付款 |
| **已付款** | 已全额收款 |
| **作废** | 已取消——**不计入**项目的已开票 |

发票上的**已收金额**是记到它上面的收款的汇总，**未收金额**是差额；都不用手填。

## 收款

**收款**（`crm_collection`）是收到的钱：金额、日期、方式（*银行转账、支票、银行汇票、其他*）、银行流水号、它核销的发票，以及所属项目和客户。对着发票登记收款，会同时改变那张发票的已收与未收金额、项目的已收款与应收余额。

## 采购合同

**采购合同**（`crm_purchase_contract`）是项目采购进来的东西：类型（*分包、软件、硬件、其他*）、供应商、金额、日期、状态（*草稿 / 生效 / 已完成 / 已终止*）、已付与未付金额。*已终止*的合同**不计入**项目的采购合同合计。

## 销售订单

**销售订单**（`crm_sales_order`）是在项目合同下下达的订单：订单号、金额、下单日期、状态（*待处理 / 进行中 / 已交付 / 已验收*）、客户和合同。订单汇总进项目的销售订单合计。

## 系统自动做的事

- **每个合计都是汇总**——已开票（不计作废）、已收款、应收余额、采购合同合计（不计已终止）和销售订单合计都在交付项目上，子记录每次保存都重算。
- **这里没有审批**——财务记录不带审批流程；管控靠上面的状态和项目自身的共享。

## 共享

四种记录都在交付项目下*由父级控制*：看得到项目的人看得到它的开票、收款、采购合同和销售订单，别人看不到。它们为了方便也带一个客户字段，但可见性从不跟随客户——通过区域规则共享给代表的客户，代表只在能看到背后交付项目的情况下才看到该客户的发票。

## 给财务的提示

- ✅ **开错的发票作废，不要删除**——作废保留了审计轨迹，也会自己从合计里掉出去。
- ✅ **收款对着发票登记，而不只是对着项目**，发票上的未收金额才诚实。
- ✅ **黄了的采购合同置为已终止，而不是删除**，理由相同。
